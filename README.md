# Apex Dental & Implant Studio — HTML/CSS/JS Prototype

This version implements the patient-facing requirements from the supplied Dental Clinics & Implant Centers Frontend Development Specification using only HTML, CSS and vanilla JavaScript (no React and no Node.js application/backend).

## Run
Open `index.html` in Chrome, Edge or Firefox. No build step is required.

## Included
- Glassmorphic sticky navigation and smooth-scroll sections
- Hero, social proof, trust micro-tags and floating availability badges
- Animated clinical metrics
- Traditional vs Apex comparison with interactive demos
- 8-treatment catalog + category filters + protocol drawer + direct booking
- Draggable/touch before-after gallery with 3 cases
- 4 specialist doctor cards and direct booking
- Virtual tour preview
- 4-step booking engine with treatment, specialist, 7-day date picker, shifts, slot states and patient intake
- 0.8s confirmation loader, unique token, Google Calendar, Apple .ics and direct PDF slip generation
- Simulated WhatsApp confirmation toast after 1.2s
- Live OPD queue / waiting room display
- 60-second 3-question smile assessment with treatment/specialist recommendation and ₹500 waiver result
- 3 video-review style thumbnails + 6 verified reviews + trust badges
- 6 FAQ items
- EMI calculator
- Contact, hours, phone, WhatsApp and Google Maps actions
- Mobile sticky booking bar, horizontal swipe carousels and 48px+ touch targets
- localStorage for last appointment
